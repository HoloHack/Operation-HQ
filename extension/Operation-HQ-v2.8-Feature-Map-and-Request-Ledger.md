# Operation HQ 2.8.1 — Feature Map and Request Ledger

This is the plain-English map of what the current extension actually does. It distinguishes shipped behavior from work that still needs a real Chrome/device test. “Local” means the information stays in the extension unless a named integration is deliberately connected.

## 1. Home and living dashboard

- **Clock and personal header**
  - Live time, date, greeting and local day context.
  - Location-aware weather once browser location is granted, with manual city entry as a fallback.
  - Cinema mode hides the whole interface in one action so only the wallpaper remains; `Alt+Z` toggles it and Escape/on-screen recovery restores the interface.
- **HQ Foresight widget**
  - Chooses one defensible next action from real unfinished tasks, deadlines, assignments, calendar items and current schedule context.
  - Shows why that action was chosen rather than presenting unexplained “AI” certainty.
  - Surfaces unfinished work, tomorrow pressure and the next useful handoff.
- **Weather widget**
  - Current condition, temperature and location state.
  - Changes its own visual atmosphere and feeds factual weather context to the background motion system.
  - Opens the complete weather panel instead of crowding the home screen.
- **Focus widget**
  - Shows the active timer and the name of the current mission.
  - Starts, pauses and opens the full focus environment.
  - Changes attitude while a session is running without blocking its controls.
- **Schedule widget**
  - Shows the current timetable block, next block and time progress.
  - Reacts to the active day and current timetable phase.
  - Opens the full Master Timetable/Schedule surface.
- **Gmail widget**
  - Shows live read-only inbox priority and unread state after Google sign-in.
  - Opens the communications hub for full sorting and handoffs.
- **Assessment Radar widget**
  - Shows imported assessment briefs waiting for review, deadlines and the most useful next step.
  - Opens the Assessment Intake/Study OS flow.
- **Daily Rhythm widget**
  - Shows habits and daily completion as a changing constellation rather than a static counter.
  - Opens the full habits/daily-task surface.
- **Widget system**
  - Living, Focus and Expanded layouts.
  - Calm, Balanced and Command-centre spacing densities.
  - Visibility controls, safe drag/keyboard reordering and remembered layout.
  - Each widget has its own silhouette, data hierarchy, empty state, movement signature and mini-to-full route.

## 2. Cinematic visual and motion system

- **Launch film**
  - Full-screen shutters, depth field, volumetric beams, rotating reactor rings, segmented aperture, scan pass, progress line and real subsystem telemetry.
  - Hands off into the live widgets only when the dashboard has actually reached its ready state.
  - Full, Compact and Off modes, a Skip control, an in-settings Preview and a hard failsafe so the animation can never trap the new tab.
- **Live procedural atmosphere**
  - A pointer-transparent visual layer draws depth, horizon/ribbon light, focus grid, widget-node connections and action pulses.
  - It responds to time, focus, weather, visible widget state and the current wallpaper palette.
  - It does not record the cursor, infer emotion or create a behavioral profile.
- **Widget movement**
  - Slow low-frequency physical attitude while idle.
  - Hover depth only on the contacted card, press compression, contact ripples and focus-within illumination.
  - Attention, completion and context events send source-positioned waves through the dashboard.
  - Arrange mode and Reduced Motion stop continuous movement.
- **Whole-interface transitions**
  - Focus scenes, privacy/zen changes and generated study atmospheres recompose the dashboard rather than changing a single accent.
  - Generated schemes use one of four distinct sequences: prism shards, collapsing iris rings, velocity cuts or expanding bloom rings.
  - The dashboard camera, dock and top controls pull back, pass through the transition and settle into the new composition.
- **Generated study atmospheres**
  - Typing a mission such as “Maths chapter 6” creates three new choices at that moment.
  - The subject, wording, time and environment influence palette, surface, shape, animation pace and spatial treatment.
  - Mathematics, Science, Humanities/HSIE, English, Technology, Languages, Creative work and general focus each have a different compositional bias.
  - No proposal is applied until the user chooses it; Regenerate creates another set.
- **Performance protection**
  - Auto, Ultra, Balanced, Efficient and Off quality modes.
  - Measured frame-rate downshift/recovery, hidden-tab pause, cached widget geometry and graphics-context recovery.
  - The pointer system updates one active card instead of rewriting every card each frame.
  - System Reduced Motion removes continuous/camera-heavy movement while preserving understandable state changes.

## 3. Nexus command intelligence

- **One entry point**
  - Open with the Nexus button or the safe `J` shortcut when not typing.
  - Suggestions, recent commands, mission shortcuts and a visible explanation of which capability will act.
- **Commands it understands locally**
  - Subject names, chapter ranges, dates, weekdays, “today/tomorrow/in N days,” durations and focus-plan language.
  - Find/open saved resources, generate a study atmosphere, review tabs/bookmarks, start focus, route to assessments/exams/calendar/mail and build a study plan.
  - Missing subject, chapters or deadline triggers one clear follow-up field instead of a guess.
- **Maths and study workflow**
  - A command such as “Prioritise Maths chapters 4–7 by Friday” becomes a reviewable plan over real flexible timetable blocks.
  - Nexus can search existing bookmarks, open tabs and saved workspaces for Cambridge or another named resource and lets the user choose the exact result.
  - After confirmation it can open Focus, name the mission, set the timer, generate three matching atmospheres and start the session.
  - The Calendar draft still has a separate Apply action so a sentence cannot silently rewrite the week.
- **Browser workflow**
  - Opens Browser Intelligence for duplicate/topic-group review.
  - Never silently closes tabs, destroys groups or rewrites bookmarks from a vague command.
- **Optional on-device AI**
  - Fast profile for lighter devices, Balanced profile for broader reasoning and Maths profile for mathematical study support.
  - Guided explanation, recall quiz, pasted-work checking, command interpretation and ambiguous-bookmark classification.
  - Models are downloaded/loaded only after explicit selection. Output is advisory and mathematical answers still need checking.
- **Official handoffs**
  - Opens Gmail, TikTok, Instagram or another official web destination when the browser extension cannot safely perform the service's private action itself.
  - Does not scrape private messages or pretend to send/reply.

## 4. Personal operations

- **Tasks**
  - Action, priority, due date, estimate, venture link, completion and structured creation.
  - Safe deduplication when another module promotes the same next action.
- **Today and tomorrow**
  - Unified briefing, quick capture, unfinished work, follow-ups, current schedule and tomorrow preparation.
  - Nightly planning prepares tomorrow separately and promotes it only when the local day changes.
- **Calendar**
  - Month, Week and Agenda views; search, navigation and selected-day detail.
  - Natural quick entry plus a structured editor for timed/all-day events, category, priority, location, notes and daily/weekly/monthly recurrence.
  - Conflict detection, while-open reminders, edit/delete and exact undo.
  - Master Timetable v8 appears as a live schedule layer without duplicating records.
- **Master Timetable v8**
  - Weekday rhythm, dated phases, school/tuition/job blocks and flexible work blocks.
  - Current phase, current block, next block and inline schedule-profile editing.
  - Review-first multi-day task/chapter planning inside real flexible capacity.
- **Focus and Deep Work**
  - Named Pomodoro mission, adjustable duration, start/pause/reset, focus history and reversible Study/Build/Reset scenes.
  - Deep Work site restrictions and intentional launch flows; active settings are never changed silently.
- **Exams**
  - Countdown, target date, subject, reverse plan, daily allocation, capacity warning and one-click next action.
- **Daily habits and weekly signals**
  - Daily checkoffs, streak/coverage signals and weekly summaries from real completion data.

## 5. Study OS and assessment intelligence

- **Assessment Intake**
  - Optional download-history connection, optional folder access and direct PDF, DOCX, text, Markdown, HTML or RTF import.
  - Extracts deadline evidence, subject, task type, description, requirements and actionable steps locally.
  - Every inferred field is reviewable before acceptance; accepted deadlines can create one exact Calendar entry and one linked Assignment.
  - Duplicate prevention, whole-intake undo and Start next step.
- **Assignments**
  - Type, weighting, deadline, estimate, requirements, progress, phase-based steps and Task promotion.
  - Timetable-capacity session proposals remain drafts until Apply.
- **Research**
  - Explicit page/selection capture, safe URL, source type, author/date, subject/assignment link, notes and workflow stage.
  - Search, filter, citation draft, export and deletion recovery.
  - Stores no scraped page body and labels unverified metadata honestly.
- **Recall Lab**
  - Subject decks, SM-2 scheduling, tags, search, session limits, suspension, lapse tracking, import/export, edit and delete undo.
  - No fabricated starter deck.
- **Native Intelligence Lab**
  - User-selected Tasks, Calendar, Assignments, Today, Captures, Notes and Gmail metadata can be assembled into labelled local context.
  - Executive brief, next priority, schedule, risk, study sprint, connections, summary, explanation, quiz, critique, rewrite and action extraction.
  - It never claims that advisory text changed the underlying apps.

## 6. Communications and media

- **Gmail organiser**
  - Read-only OAuth scope.
  - Urgent, School, Work, Venture, Social, Finance, Updates and Personal lanes.
  - Shows sender/subject/label reasons, supports local correction and always opens the original message in Gmail.
  - Reviewable consequences: create a local Task, add a local Calendar reminder, record a follow-up or open the official social inbox.
  - Cannot send, archive, delete, label or modify Gmail.
- **Spotify**
  - Optional official connection, player surface and isolated playback sandbox.
  - Device/account behavior depends on Spotify and must be tested in the target browser.
- **Voice/provider adapters**
  - Optional Claude and ElevenLabs client surfaces are present for user-supplied credentials.
  - Secrets are session-scoped where possible and are not silently bundled into the extension.

## 7. Browser and knowledge organization

- **Bookmark sorter**
  - Topic-first two-level taxonomy, including dedicated Mathematics and Science paths rather than grouping everything by YouTube/Google/platform.
  - Exact-link learning so one YouTube video or Google document cannot teach the category for every other item on that service.
  - Full Sort, Inbox Sort and Deep Review.
  - High-confidence items can file automatically. Anything uncertain stays in its current folder and appears in the accuracy gate for an explicit, prefilled decision; no Review Queue or Uncategorized folder is created.
  - Optional page metadata and optional local-model classification improve genuinely ambiguous titles.
  - Operation history and exact undo; cleanup can remove only empty folders proved to have been created by Operation HQ.
- **Tab and group optimizer**
  - Detects duplicates, repeated topics and group opportunities.
  - Changes remain explicit; the current window is not silently destroyed.
- **Workspaces**
  - Save/restore tabs, pins and native tab groups.
  - Cross-reference saved tabs with bookmarks, refresh stale saved metadata and preserve saved-only references.
- **Forgotten bookmark resurfacing**
  - Surfaces older saved resources without inventing new content.

## 8. Notes, capture and ideas

- **Notes**
  - One canonical versioned document, serialized autosave, rich editor and plain-text recovery mode.
  - Search, word count, typography, captured-snippet drawer and export.
  - Exact-triplication repair with a recoverable pre-repair copy; ordinary repeated lines are not silently removed.
- **Capture Inbox**
  - Quick ideas/actions flow into one local inbox and can be promoted deliberately.
- **Idea Vault and Idea Radar**
  - Store, review and resurface ideas without fabricated starter content.
- **Venture Dashboard**
  - Project/venture tracking, progress and linked actions; deeper GitHub/project adapters remain roadmap work.

## 9. Gleam social-confidence app

- Hidden from the default dashboard and opened only when requested.
- Six practice tracks: Conversation, Listening, Clarity, Assertiveness, Teamwork and Speaking.
- Original micro-lessons, knowledge checks, real-world missions, deterministic simulations and a wording-response lab.
- Pre-conversation rehearsal maps with flexible openings, useful questions, clear message structure, reality checks and exits.
- Adaptive practice suggestions based on selected tracks and completed evidence.
- Real-rep reflections, practice sessions, active days, coverage, before/after self-reflection, export and module-only erase.
- No camera, microphone, contacts, diagnosis, manipulation tactics or fabricated personality score.

## 10. Privacy, accessibility and recovery

- Manifest V3, local-first storage and versioned non-destructive migrations.
- Explicit optional permissions for downloads/page metadata rather than permanent silent access.
- Encrypted backup option, JSON export and recovery controls.
- Shared context and Calendar use serialized single-writer transactions with exact undo.
- Safe Mode is crash recovery, not a normal operating mode. In 2.8 it is per-tab and can be left from the top recovery strip or Settings → System Health → **Exit safe mode and reload**.
- Visible loaded-build identity and copyable diagnostics.
- Keyboard focus, named dialogs, Escape behavior, responsive mobile layout and system Reduced Motion support.
- No dummy tasks, emails, calendar events, assignments, decks or ventures on a fresh install.

## How the animation request was accounted for

| Requested feeling | Current implementation | Why it is more than a small hover effect |
|---|---|---|
| Cinematic boot | Shutters, space field, beams, aperture, reactor rings, scan, staged labels, progress and dashboard handoff | It is a full-screen multi-layer sequence tied to real startup milestones, with Skip and failsafe paths |
| Moving widgets | Low-frequency attitude, hover depth, press compression, contact ripples, event waves and context states | Movement is continuous but restrained, and each interaction has a physical response |
| Anime-edit-like mode flow | Prism, iris, velocity and bloom transition families plus dashboard/dock camera reframing | Theme changes alter composition, timing, scale, light and geometry across the entire interface |
| Different study moods | Three newly generated choices per named mission; subject-aware palette, shape, surface and pace | The choices are created from the current mission rather than picked from a tiny fixed theme list |
| Dynamic behavior | Time, weather, focus, schedule, inbox and task pressure update widget content and factual motion state | The dashboard changes because its underlying situation changed, not because a random animation loop fired |
| No lag/trapping | Measured quality downshift, hidden-tab pause, one-card pointer depth, cached geometry, Compact/Off and Reduced Motion | The cinematic layer is governed by performance and can always be bypassed |

The supplied smoke-test recordings confirmed that the launch film and some widget animation were present, but also revealed concrete failures around Safe Mode, wallpaper results and panel close/interaction spacing. Those were treated as defects and addressed through 2.8.1.

Higgsfield was useful for structured inspection of the recording. A fixed generated video was not embedded into startup because it would be heavy, would not adapt to arbitrary live schemes, and could worsen the lag already observed. The extension instead uses native layered motion that can react to real state and degrade safely.

## What is still genuinely open

- Real Chrome clean-install and upgrade testing on the user's exact device/profile.
- A full visual matrix at 1920×1080, 200% zoom, keyboard-only and Reduced Motion.
- Live Wallhaven quality/availability checks for every named search; external providers can return no relevant result.
- Gmail revoke/reconnect and real WebGPU model download/inference tests on the target hardware.
- External adapter platform and optional sync backend.
- Deeper Venture/Build integrations, private retrieval index, notification/digest controls and official calendar adapters.
- Broader command grammar and evaluated AI accuracy. The current deterministic layer is reliable for its declared intents; it is not a general autonomous agent.

That is why the strict roadmap score is **71%**, not 100%. The critical local dashboard, study, command, browser, Gmail, Calendar, timetable, motion and recovery foundations are substantially implemented; the remaining percentage is dominated by real-device release gates and large external-integration stages, not hidden placeholder features.
