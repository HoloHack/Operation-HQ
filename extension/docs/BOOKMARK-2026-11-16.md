## Reproduced and repaired

1. Deep Review admitted protected Inbox-title bookmarks that Full Sort excluded. Candidate collection now shares the protection, and mutation rechecks the reviewed title.
2. Page-evidence cache stripped all fragments, so `#/math` and `#/music` reused one topic. Foreground and automatic-worker lookups preserve hash-router identity; ordinary heading anchors still share evidence. Static fetching refuses hash-router content because shared HTML metadata cannot prove a rendered route's meaning. Old shared-shell entries cannot populate route evidence.
3. Restoring a pending decision replaced its URL/title/parent with current values while retaining old evidence. Changed/deleted resources now lose that stale decision and selection; the bookmark itself is never changed by restoration.
4. Eight metadata records could exceed the model's 9,000-character input limit, cutting JSON and dropping later records. Complete records are now packed into sequential requests below 8,500 serialized characters, accounting for escaped metadata.
5. Model output accepted invented roots/subfolders, duplicate IDs and arbitrary reasons. Output now requires exact submitted unique IDs, taxonomy membership, known confidence labels and bounded string reasons. Duplicate decisions invalidate that ID rather than last-wins. Malformed/oversized output reports failure; omitted items remain unresolved.

No new model, runtime, permission, provider, schema or network data flow was added. Automatic background sorting still never fetches arbitrary page content or starts a model. AI-only categories remain suggestions until owner confirmation; self-reported confidence is not proof.
