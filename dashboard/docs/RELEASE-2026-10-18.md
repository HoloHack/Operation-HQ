# Operation HQ — 18 October 2026 reliability release

[Open your dashboard](https://operation-hq-command-center.shour-ya11.chatgpt.site). Dashboard version 12 is published; companion version 3.2.4 is merged in [PR 14](https://github.com/HoloHack/Operation-HQ/pull/14).

## In plain language

- New bookmarks no longer vanish from the sorting process when another operation is busy. Pending work survives a worker restart and its status is visible.
- Exact corrections no longer contaminate different deep pages or query-based chapters on one website. An old folder is no longer treated as proof that its contents were correctly categorised.
- Undo waits for automatic sorting, restores recorded positions, and preserves unrelated user folders. Uncertain links remain where they are until there is real evidence.
- Browser tools and the website share the Study desk's Paper/Night design, spacing and bounded drawers. Chrome-only tools still run in the companion.
- The focus timer survives a refresh and reflects start/pause/reset across tabs on this device.
- Closed native panels stop participating in layout/paint. This improves the rendering boundary; the all-tools memory target is still not met or certified on your Mac.

## Install the companion update

1. Unzip `Operation-HQ-Browser-Companion-3.2.4.zip` to a permanent folder. The inner folder contains `manifest.json`.
2. If HQ is already installed unpacked, copy the new contents into its existing folder, open `chrome://extensions`, and click **Reload**. Do not uninstall or clear its storage. If no HQ companion is installed, enable Developer mode and choose **Load unpacked** for the inner folder instead.
3. Pin the companion and confirm **3.2.4** in its popup. Refresh open HQ pages. Open the dashboard; if needed, enable its exact-origin bridge in the popup. Planning pairing is a separate account/profile confirmation in dashboard Settings.
4. For an existing bookmark collection, choose **Preview**, then **Sort + verify evidence**. Approve page-reading permission only if you want HQ to read real titles/descriptions for unclear links. Automatic sorting applies to newly saved links while its switch is On. Ambiguous links are not randomly moved to make a counter reach zero.

Your real Chrome profile, Gmail approval/revoke/reconnect and Mac performance still need owner-device acceptance. Test fixtures cannot grant your OAuth consent or prove your own bookmarks were correctly filed. No new Supabase project, API key or Gmail scope is needed for this release.
