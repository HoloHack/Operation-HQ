# Operation HQ reliability release — 8 October 2026

> Historical first release on this date. The later [bridge and recovery update](RELEASE-2026-10-08-BRIDGE-AND-RECOVERY.md) supersedes its recovery and browser-testing limitations.

## Delivered

- Merges preserve all task/event/planning records instead of slicing the union to storage limits. A 1,500 + 1,500 task conflict retains all 3,000 records. Oversized writes remain unsaved with an explicit export-before-close message; incoming oversized imports are refused.
- Keeping both notes versions preserves the full document even above the save limit. Local edits cannot silently cut it back down.
- Maths chapter missions ask for a real deadline and 5–180 minute estimate. Chapters 5, 7, 8 and 10 remain four separate actions. Repeated application reuses active tasks and preserves their original dates. Invalid and incomplete chapter lists are rejected.
- Task search and 50-row incremental rendering bound initial task and agenda DOM size. Theme transition layers are removed after completion, including reduced-motion mode. This is a resource reduction, not a RAM measurement.
- Reviewed security updates: Next/eslint-config-next 16.3.8, React/DOM/RSC 19.2.8, Vite 8.0.16, and targeted vulnerable transitive dependencies. The seven-day package-age policy remains enabled.
- GitHub dashboard checks cover tests, TypeScript, build and production dependency audit. Sites remains the production source/deployment authority; GitHub is a reviewed maintenance snapshot rather than an automatic second deployment writer.

## Evidence

24 executable regression tests pass. TypeScript and the production build pass. Tests use isolated in-memory snapshots and SQLite test doubles, not production accounts. Production dependency audit: zero known findings on 8 October. Full audit: one high finding in braces (no patched release available) and one moderate finding in legacy esbuild 0.18.20 through drizzle-kit's old loader. Neither is a production dependency; do not expose development tooling to untrusted hosts or untrusted build patterns. They remain follow-up work, not waived as fixed.

## What is still unfinished

This is a bounded reliability release, not 100% completion of the product roadmap. Automatic rescheduling, chapter-level Cambridge navigation, full recurring calendar/timetable views, durable offline outbox, deletion synchronization, restore UI and model-driven commands remain unfinished. The command router is deterministic; it is not a general-purpose language model.

Current extension 3.0 source recovery is blocked by the archive transfer error. The repository's 2.8.1 repair work must not replace or be presented as a tested 3.0 installation. Browser-only bookmarks, tab groups, Gmail OAuth, real provider calls, downloads intake, WebGPU/local models and the extension bridge cannot be verified from dashboard tests. Never mutate live bookmarks or email as a test.

No target-Mac renderer/GPU memory or animation frame-pacing measurement was possible. The 300 MB goal is unverified. Visual/keyboard browser testing is also unavailable in this environment. Builds and static UI contracts do not prove every screen is correct.

Overflow preservation is currently in page memory, not a durable outbox. Export pending work before closing; the unsaved status remains visible. This repair prevents silent truncation but does not remove the bounded server snapshot capacity.

## Database decision

Retain the existing account-scoped D1 store. No Operation HQ Supabase project exists in the connected project inventory. A second database would add migration and synchronization failure modes without solving this release's bugs. No new service, billable project, permissions, schema migration or production data edits were made.
