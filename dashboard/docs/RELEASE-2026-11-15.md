# Operation HQ — planning and reliability continuation

The approved Study desk, account data stores, extension identity, permissions and planning protocol are preserved. This release continues the roadmap; it does not finish the whole product vision.

## Delivered behavior

- Automatic bookmark batches stop after a failed move and recheck the recovery journal before each subsequent link. Three repeated API failures stop polling; cancelling the last queued link clears its alarm. Existing classification, exact corrections, protected folders and Undo remain.
- Dashboard alternating weeks now agree with the companion's job weeks and explicit overrides. Unsupported intervals are refused rather than silently flattened.
- Master v8 source corrections are available through Schedule → Refresh Master v8. Existing saved profiles stay intact until confirmation. A pre-refresh managed-profile copy can be restored. Job-evening transitions are labelled provisional; competition workload and inherited weekend detail remain source limitations.
- Calendar imports preview a finite 1–90 day ICS snapshot. Daily/weekly recurrence, bounded counts, matching exceptions/additional dates, all-day spans and IANA/UTC conversion are supported. Existing edits, deletion markers and duplicates are protected; imports have durable account-scoped undo. Monthly rules, edited recurring instances, overnight/sub-minute entries and ambiguous/skipped DST times fail the complete preview with an explanation. This is not a live provider connection.
- Planning can use only flexible timetable blocks, count retained future sessions toward task estimates before their deadlines, preserve breaks across separate blocks and show every proposed session before Apply.
- Commands can give a factual day brief, find literal matches in local planning with source-workspace links, and start a reviewed bounded focus session. Examples: “Brief me for today”, “Find my maths notes”, “Start 50-minute focus on maths”, “Plan my week”. No general-model intelligence or invented Cambridge links are claimed.
- Calendar file controls fit narrow layouts. The opaque companion desk no longer requests legacy per-row blur/animation/compositor hints.
- Next.js and Zod are updated to patched versions identified by the release audit; matching Next lint tooling is updated too. No application schema or OAuth scope changes are needed.
