## What is available

- Calendar day/week/month/agenda views, event details, repeating timetable guidance, current/next/tomorrow context and ICS export.
- Reviewed study scheduling that uses flexible study blocks while protecting school, tuition, meetings, sport, travel and rest. Stale previews stop, and undo preserves unrelated events.
- Explicit browser/account pairing, visible-tab planning exchange and reversible disconnect. Both notes versions are retained during first pairing; conflicting updates stop instead of overwriting.
- Searchable release shelf, exact edition selection, anime airing countdowns, supported VIZ metadata, manual source-backed dates and last-verified data on errors. Date not announced is truthful when no date is available.
- Release checks run while the dashboard is visible: normally six-hourly, hourly near release, and fifteen minutes after errors. They do not provide closed-dashboard desktop reminders.
- Expanded deterministic commands route study, calendar, tasks, unfinished work, notes, themes, release tracking and browser tools.

## Companion and first use

Install/reload companion 3.2.0 from the tested source's extension directory. Existing users should retain their unpacked extension path and profile; do not uninstall merely to upgrade. Enable dashboard access in the companion popup, then use Settings > Paired planning and explicitly confirm the account/profile before pairing. Publication does not silently read or pair a browser.

No Supabase project, new API key or original 3.0 ZIP is required for this release.
