## 1. Load the extension
1. Go to `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked** → select the extracted `Operation-HQ` folder
4. Open a new tab — you should see the dashboard immediately.

Tasks, notes, ventures, and wallpaper settings all work right away with zero setup and begin with honest empty states.
Bookmark auto-sort works right away too — permissions are already declared.

Gleam is intentionally hidden from the default living dashboard. Open **More → Gleam**, press `Cmd/Ctrl+K` and search for Gleam, or tell Nexus **open Gleam**. Its first run asks only which skills you want to practise, your own comfort baseline, and a daily time target.

## 2. Gmail setup (10–15 min, one-time)
This is the only piece that may need configuration, because Google requires the
OAuth client to match the installed extension ID.

1. Go to https://console.cloud.google.com/ and create a new project (any name, e.g. "HQ NewTab").
2. In the search bar, open **APIs & Services → Library**, search "Gmail API", click **Enable**.
3. Go to **APIs & Services → OAuth consent screen**.
   - User type: External. Fill in app name/email. Add yourself as a test user.
   - Scopes: add `https://www.googleapis.com/auth/gmail.readonly`.
4. Go to **APIs & Services → Credentials → Create Credentials → OAuth client ID**.
   - Application type: **Chrome Extension**.
   - You'll need your extension's ID first — go to `chrome://extensions`, find
     Operation HQ, copy the ID string under its name.
   - Paste `cbgepkbfmcahdpahipkdeahppfbggjok` into the **Item ID** field. The packaged manifest key keeps this ID stable across unpacked folders.
5. Copy the generated Client ID (ends in `.apps.googleusercontent.com`).
6. Your saved Client ID is already present in `manifest.json`: `909480994423-tv8bkcfd8v8il907lph0t2b72oh165k6.apps.googleusercontent.com`. A Chrome Extension OAuth client does not use a client secret in this extension.
7. Go back to `chrome://extensions`, click the reload icon on Operation HQ.
8. Open a new tab, click **Connect** in the Inbox panel, sign in, approve.

## 3. Wallpapers, Weather, and Privacy

Wallpaper categories work without API keys through Wallhaven fallbacks. Optional
Unsplash and Pexels keys can be added in Settings. If an image is unsuitable,
use **Hide this wallpaper**; the extension remembers up to 500 hidden images on
this device. The list can be cleared from Settings.

Weather uses browser location automatically by default. After installing or reloading the extension, approve Chrome’s location request. On macOS, Google Chrome must also be enabled under **System Settings → Privacy & Security → Location Services**. If blocked, Weather’s recovery button opens Chrome’s location settings; manual city mode remains available and private.

## 4. Assessment Intake setup

1. Open **Assignments → Assessment Intake**. Direct **Import files** works without any additional Chrome permission.
2. For automatic filename notifications, click **Connect download history**. Chrome should ask for the optional Downloads permission at that moment. This does not let Operation HQ read the downloaded document.
3. To analyse actual files automatically, click **Grant Downloads folder** and choose the folder in Chrome’s directory picker. This is a separate read capability. Use **Forget folder** or **Disconnect history** whenever you want to revoke either path.
4. Review the detected title, subject, deadline and quoted deadline evidence. Click **Accept + add deadline** only when they match the original brief.
5. Use **Add all steps**, **Start next step**, or **Plan sessions**. Session proposals do not touch Calendar until you review and apply them.

The built-in PDF reader intentionally rejects image-only or unusually encoded PDFs rather than guessing. In that case, import a DOCX/text version or paste the brief into the Native Intelligence Lab. Full file text is never persisted or uploaded; only derived assessment details remain after the tab closes.

## 5. NEW — The 5 first-principles features
- **Idea Vault (💡)** — stamp any idea's exact text with a SHA-256 hash +
  timestamp. Proof you had it at a specific moment; the text stays local,
  the hash is what you'd ever share. "Copy receipt" gives you a portable
  block you could email yourself for an independent external timestamp.
- **Capacity-aware planning** — Today's Plan archives each day's
  planned-vs-completed minutes by day-of-week and feeds that back into
  future plans, so busier weekdays become lighter automatically from your
  real completion history.
- **Pre-mortem warnings** — before a plan is presented as final, it's
  checked against your historical completion capacity for that day-of-week.
  If it's 40%+ heavier than what you've actually finished on days like this,
  you get a warning naming the most likely task to slip — before the day,
  not after.
- **Professional View (💼)** — different from Privacy Mode. Privacy Mode
  hides-with-a-tell; Professional View makes Daily Non-Negotiables and the
  streak genuinely not exist in the page, and filters Operation HQ to
  ventures you mark "professional" (Settings). For screen-sharing with a
  Momentum Academy co-founder or a client without it reading as a student
  habit tracker.
- **Idea Radar (🔭)** — real web search (via your Claude key, Anthropic's
  server-side search tool) checking whether your venture names are showing
  up elsewhere. Manual by default; weekly auto-check is opt-in.
